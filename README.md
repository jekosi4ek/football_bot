# ⚽ Football Manager Telegram Bot

Telegram bot for managing amateur football games: player rosters, balanced team
division, and a match half-timer with a whistle signal.

---

## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

> **Windows/Mac:** Install [ffmpeg](https://ffmpeg.org/download.html) and add it to PATH.  
> **Linux:** `sudo apt install ffmpeg`

### 2. Configure

```bash
cp .env.example .env
# Edit .env and set BOT_TOKEN=<your token from @BotFather>
```

### 3. Generate the whistle sound (once)

```bash
python generate_sound.py
```

### 4. Run

```bash
python bot.py
```

## Bot Commands

| Command | Description |
|---------|-------------|
| `/start` | Show main menu |
| `/add_player [name]` | Add a player (or send a voice message) |
| `/list_players` | Show all players with strength |
| `/remove_player [name]` | Remove a player |
| `/set_strength [name] [1-3]` | Set player strength level |
| `/auto_divide [n]` | Divide players into n balanced teams |
| `/create_team [name]` | Create a named team manually |
| `/show_teams` | Show current team rosters |
| `/start_match [min]` | Start half-time timer (default 7 min) |
| `/pause_timer` | Pause the timer |
| `/resume_timer` | Resume a paused timer |
| `/stop_match` | Stop the timer |

**Strength levels:** ⭐ Weak (1) · ⭐⭐ Average (2) · ⭐⭐⭐ Strong (3)

## Voice Messages

Send a voice note with any of these phrases to add a player automatically:

- *"Додай Іванця"*
- *"Гравець Петро Марченко"*
- *"Запиши Олег"*

Uses Google Speech Recognition (free, requires internet).

## Deploy to Railway

1. Push this repo to GitHub.
2. Create a new project on [railway.app](https://railway.app) → **Deploy from GitHub**.
3. Add environment variable `BOT_TOKEN` in Railway's Variables tab.
4. Railway will use `nixpacks.toml` to install ffmpeg automatically.

> **Note:** Railway's free tier uses ephemeral storage.  
> For persistent data, add a **PostgreSQL** plugin and update `DATABASE_PATH` or
> switch `database.py` to use `psycopg2`.

## Project Structure

```
football_bot/
├── bot.py                   # Entry point
├── config.py                # Settings (from .env)
├── database.py              # SQLite CRUD operations
├── generate_sound.py        # One-time whistle MP3 generator
├── handlers/
│   ├── players.py           # /add_player, /list_players, etc.
│   ├── teams.py             # /auto_divide, /show_teams, etc.
│   ├── match.py             # Timer logic + /start_match, /pause_timer, etc.
│   ├── voice.py             # Voice message → player name
│   └── callbacks.py         # All InlineKeyboard button handlers
├── services/
│   ├── team_divider.py      # Greedy strength-balancing algorithm
│   └── voice_recognition.py # OGG→WAV + Google STT
├── utils/
│   └── keyboards.py         # All InlineKeyboardMarkup factories
└── sounds/
    └── whistle.mp3          # Generated by generate_sound.py
```
